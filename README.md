<h2>📌 About The Project</h2>

<p>
<b>Move It</b> is a responsive delivery service frontend website designed to provide a clean and user-friendly experience for customers looking for fast and reliable moving or delivery services.
</p>

<p>
The project mainly focuses on modern UI design using <b>Bootstrap</b> components and responsive layouts.
</p>

<hr>

<h2>✨ Features</h2>

<ul>
  <li>🚚 Modern delivery service landing page</li>
  <li>📱 Fully responsive design</li>
  <li>⚡ Built mainly using Bootstrap</li>
  <li>🎨 Clean and attractive UI</li>
  <li>🧩 Reusable Bootstrap components</li>
  <li>🌐 Cross-browser compatible</li>
</ul>

<hr>

<h2>🛠️ Tech Stack</h2>
